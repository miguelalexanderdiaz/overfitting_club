This is a blog where I share thoughts, opinions, and tutorials about data science, machine learning, and statistical concepts. Built with Quarto, this site explores both practical implementations and theoretical foundations of data science.

## About

The Overfitting Club is my personal space to document my data science journey, share what I learn, and hopefully help others along the way. The blog is organized into several sections:

- **Thoughts**: Personal reflections, opinions, and insights on data science topics
- **Tutorials** *(coming soon)*: Step-by-step guides organized by topic:
  - **Agents**: Building and working with AI agents
  - **Deep Learning**: Neural networks and deep learning implementations
  - **MLOps**: Machine learning operations, deployment, and best practices
- **Papers** *(coming soon)*: Paper reviews, summaries, and discussions
- **About**: More about me and this blog

## Contents

The repository is structured as a Quarto website project:
```
overfitting_club/
├── blog/
│   ├── _quarto.yml          # Site configuration
│   ├── thoughts.qmd         # Thoughts section (active)
│   ├── tutorials.qmd        # All tutorials index (planned)
│   ├── agents.qmd           # Agents tutorials (planned)
│   ├── deep_learning.qmd    # Deep Learning tutorials (planned)
│   ├── mlops.qmd            # MLOps tutorials (planned)
│   ├── papers.qmd           # Papers section (planned)
│   ├── about.qmd            # About page
│   └── assets/              # Images, styles, and resources
└── docs/                    # Generated website output
```
